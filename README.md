## Личный проект — NOVA AI

NOVA AI — проект персонального ИИ-ассистента на Python. Направления проекта: интеграция языковых моделей через API, взаимодействие через Telegram, память ассистента и автоматизация задач.

### Мой вклад

- Формулирую задачи для ИИ и уточняю требования к изменениям.
- Запускаю предложенные решения и проверяю поведение приложения.
- Передаю сообщения об ошибках и результаты проверок для дальнейшего исправления.
- Использую работу над проектом для изучения разработки и устройства ИИ-ассистентов.

**Формат работы:** основную часть кода генерируют ИИ-инструменты. Самостоятельное программирование пока изучаю; наличие технологий в проекте не означает самостоятельного владения всем стеком.

## Какие задачи готов рассматривать

Начальный уровень, с понятными требованиями и возможностью обратиться к более опытному специалисту:

- Тестирование приложений по заданным сценариям и описание шагов воспроизведения ошибок.
- Подготовка и уточнение запросов к ИИ под конкретные задачи.
- Проверка результатов работы ИИ на соответствие требованиям.
- Помощь с прототипами простых ИИ-решений под руководством специалиста.
- Техническая поддержка в пределах текущих знаний с передачей сложных случаев специалистам.

## Что изучаю

Python, API, JSON, работу с контекстом и памятью ИИ-ассистента, взаимодействие приложения с инструментами.

**Направления развития:** тестирование, техническая поддержка, ИИ-инструменты и автоматизация. Системное администрирование и DevOps рассматриваю как направления дальнейшего обучения.
