## Личный проект — NOVA AI

NOVA AI — проект персонального ИИ-ассистента на Python. Направления проекта: интеграция языковых моделей через API, взаимодействие через Telegram, память ассистента и автоматизация задач.

### Чем занимаюсь в проекте

- Формулирую задачи для ИИ и уточняю требования к изменениям.
- Запускаю предложенные решения и проверяю поведение приложения.
- Проверяю результаты на соответствие поставленной задаче.
- Передаю сообщения об ошибках и результаты проверок для дальнейшего исправления.
- Уточняю запросы к ИИ по результатам работы над проектом.

**Формат работы:** использую AI-assisted подход с Claude и OpenCode. Основную часть кода генерируют ИИ-инструменты; мой вклад — постановка задач, запуск и проверка решений, обратная связь по ошибкам и результатам.

## Интересующие задачи для сотрудничества

- Тестирование приложений по заданным сценариям и описание шагов воспроизведения ошибок.
- Подготовка и уточнение запросов к ИИ под конкретные задачи.
- Проверка результатов работы ИИ на соответствие требованиям.
- Участие в работе над прототипами ИИ-решений.
- Техническая поддержка с согласованным объёмом задач.

## Технологический контекст проекта

Python, API, JSON, контекст и память ИИ-ассистента, взаимодействие приложения с инструментами. Этот список описывает технологии и темы проекта, а не подтверждённое самостоятельное владение всем стеком.
